# research-methods-skill

一个 Claude Code skill，收录通用化的科研工作流方法：文献检索与分组、研究空白与选题、实验排错与验证、论文与引言写作、投稿前自查、基金与过程文档写作、基于发文统计的导师筛选，以及科研心态工具。

English version: [README.md](README.md)

本仓库的内容是对公开科研方法资料的通用化概括。书中和课程中的具体案例、人名和个案都已去掉，示例均标注为假设。本仓库不复制任何原文。

如果你是权利人并认为某些内容侵犯了你的权益，请开 issue，我们会删除相关内容。

## 安装

将 `research-and-paper-writing-method/` 复制到 `~/.claude/skills/` 即可。
