# 二次分组（细分）、去重、排他分组与"验"（从 0 到 1）

来源：通用科研方法的归纳整理（已去除原始出处中的具体案例、人名与机构）。

适用触发：二次分组 / 细分 / 三次分组 / 细分方向 / 去重 / Find Duplicates / 排他性分组 / 非排他分组 / 未分类 / 摘要要不要扩展 / 下全文 / 验证 idea / 从 0 到 1 / 可行性 / 实验验证 / 摘录 / 实验验证文件 / 中转组。

核心思想：粗分给出领域地图，细分聚焦到自己要做的方向，去重保证库干净，"验"用最少工作量判断 idea 是否可行，避免做到一半推倒重来。

---

## A. 去重与库的整理

### A1. 多源合并流程
1. 每个数据库分别检索（如两个主流综合数据库），两个都跑，结果导入同一个文献库。
2. 导出：选择支持摘要与关键词的通用格式（如 RIS）；数据库单次导出条数有上限的，分批导出。
3. 文献管理软件中新建库（文件名短、目录浅）。导入时选对应格式；重复项设置先选择"全部导入"，便于检查条数。
4. 建元记录（以 `1-` 开头，置顶），写明每个数据库的检索式与日期。
5. 更新元记录，写明数据库组合。
6. 去重：使用软件的查找重复功能。先取消执行、查看结果，疑似重复的项会以颜色标出。
7. 人工复核：建临时分组"1"（确认不重）与"2"（待删），删除时移入回收站。
8. 检查判重设置：可暂时去掉作者字段的比较，观察作者格式差异造成的漏判。
9. 去重完成后删除临时分组。

### A2. 去重注意事项
- 标题相同但作者不同（如多篇同名章节标题）不是重复，必须人工确认。
- 作者姓名写法差异（全名与缩写混用）会导致同一篇被判为两篇。
- 去重后残留少量标题略有差异的重复，可以接受。
- 检索条数与导入条数可能不一致，记录差异即可。

## B. 排他性分组与非排他性分组

### B1. 排他性分组（直奔主题）
适用：已明确关键词，想直接找相关文献。
1. 搜索栏选择在关键词、摘要、标题中检索，各行之间用逻辑"或"连接，关键词如示例（假设）`某关键词`。
2. 文献较少（几十篇以内）时直接建分组，不必细分。
3. 标题结果很少时，才扩展到摘要和关键词（这是扩展判据）。
4. 逐篇浏览标题，相关的拖入"参考"分组。
5. 处理完后，把原分组改名为"XX未分类"，形成排他关系（已分组文献从未分类中移除）。
6. 分级标签：参考、重点参考、待定。吃不准的进"待定"。

### B2. 非排他性分组（看全貌）
适用：先了解领域全貌，关键词会囊括大量文献。
- 一篇文献可同时在多个分组，提供冗余，降低单次操作失误的风险。
- 代价是多次分组、速度慢。吃不准就随便选一种，文献都在库中。

### B3. 选择原则
| 情况 | 选择 |
|---|---|
| 关键词清楚，直奔主题 | 排他 |
| 需要了解全貌 | 非排他 |

## C. 读摘要的时机与"吞 / 吐"

- 标题 → 摘要 → 全文。能用标题判断就不读摘要；能用摘要判断就不读全文。
- 只在需要制定方案或写作时才读正文。
- 鲸吞法的两个阶段：
  - "吞"（检索与导入）：尽量全，允许冗余。
  - "吐"（分组与阅读）：只把有价值的文献拿来深读，减少耗时。
- 货比三家：读文献（尤其精读）是付出时间的成本，先把同类文献浏览一遍，再决定读哪一篇。

### C1. 扩展到摘要的判据
- 标题结果很少（几十篇以内）→ 扩展到摘要。
- 标题结果很多（几百到几千）→ 不扩展，只用标题结果即可。
- 扩展后结果多（如超过 200 篇）且抽样相关度低于约 10% → 不扩展。
- 扩展前先随机抽约 10 篇测试相关度。

### C2. 摘要快速定位法
- 找形貌、表征、特征等关键词（如 morphology、characterized by），看其前后语境。
- 示例（假设）：某句中出现 "characterized by 某表征手段"，只说明测试手段，不一定涉及研究对象本身的结构。
- 示例（假设）：某句中出现 "rather than 某因素控制"，说明作者不侧重该因素，可略过。

## D. 其他关键词分组与交集

1. 浏览"未分类"标题，抓取新的特征词。
2. 对每个特征词建分组，分组名带搜索词，即使结果为 0 也保留。示例（假设）：`方向A|方向B`，若只有方向A有结果，也要保留，说明这个方向在库中没有。
3. 检索词精简：去掉冗余修饰，保留核心词；注意单复数。
4. 撇号变体：英文所有格的撇号有两种写法，都要搜。
5. 在未分类栏或全字段中检索，只在未分类中找（排他模式）。
6. 同一篇可能同时属于两个关键词，排他模式下只留在先出现的分组中，仍在库中。
7. 标题明显与主题无关的文献直接排除。
8. 交集思想：多个分组的交集可能是相对空白的方向。

## E. 可对标一篇的变通版

适用：毕业迫在眉睫（同 topic-selection-and-ideas.md 第 10 节，此处补充操作细节）。
1. 找最可对标的一篇。
2. 从摘要关键句中提取：研究目的、方法、涉及平台或对象。
3. 把平台、对象替换为自己的。
4. 全文翻译交给翻译工具或大语言模型，但仍需逐句核对。
5. 不能抄袭，要按实际研究调整。

## F. 细分（二次分组）

### F1. 准备工作（分组前）
1. 把细分方向涉及的同义词、缩写、上位词、下位词全部在总文献库中搜索补全。
   - 示例（假设）：若某方向为"材料A涂层"，除主词外，还要搜其缩写、常用别名、连字符变体、相关材料名等，逐一建组。
2. 搜索范围：宜把相关的一次分组合并，再统一做二次搜索，避免逐个分组重复搜或漏检跨组文献。

### F2. 高频错误：以为必须分类完
- 鲸吞法本就带入一定比例的无关或弱相关文献（相关度高于约 40% 即可执行）。
- 目标是获得 idea 与写作素材，不是分类完成。
- 未分类文献可以阶段性搁置。

### F3. 二次分组的标准循环
1. 在某一次分组内（不是在未分类中）按日期降序浏览标题，提取特征词。
2. 在该分组内检索该词，相关度高则建二级分组（如"主词+特征词"）。
3. 分组名要与一次分组中的同名分组区分，避免混淆。
4. 从"未分类"中去除已归入的文献，未分类数量应持续下降。
5. 到后期，过于稀少的词可用中文名归纳收纳。

### F4. 精简原则（二次分组中同样适用）
- 复合词只搜其中一部分会误中无关结果。示例（假设）：只搜 `roll` 会误中 controllable、controlled，应搜完整词 `microroll`。
- 连字符词直接搜会漏掉写法变体。示例（假设）：`double-layer` 直接搜会漏掉 double-shell-structured 等写法，改搜 `double`，再人工过滤无关结果。

### F5. 鱼塘抓鱼
- 分组越往后，搜索范围内文献越少，特征词越容易精确命中。
- 范围越来越小，目标越来越容易定位。

### F6. 形貌类通用特征词
- 论文标题中的 like、inspired（受……启发）、shaped 等词几乎总与形貌研究相关，可批量建组。
- 语义模型难以把这类无语义关联的词与主题关联，是人工判断的独特价值。

### F7. 组集管理（批量去重）
- 新增十几个二次分组后，建"已分类"组集，把所有相关二级分组拖入。点击组集即可一次选中全部已分类文献。
- 一次分组不要放入该组集，否则会错误清零"未分类"的计数。
- 每轮新建分组后，用组集批量去重。

### F8. 分组改名与扩充
- 新增同义特征词，追加到分组名（用 `|` 连接）。示例（假设）：`主词+failure` → `主词+failure|Degradation` → 最终改为中文名。
- 分组名对应的检索词可以是多个，改名时保留所有来源词的线索。

### F9. 排序方式选择
- 刚开始分组：按日期（随机，无偏）。
- 后期找不到共同特征词：改按标题（同前缀词会聚集）或期刊（同刊文献主题相近）。

### F10. 反向排除
- 为"不相关"文献建一个分组，集中收纳，用排除法净化其余分组。

## G. "验"：从 0 到 1

### G1. 核心逻辑
- 研究型论文以图表为核心，结果与讨论围绕图表展开。因此先做出图表（研究工作），再写引言。
- 验证阶段的文献阅读只为判断 idea 是否可行，不做全文通读。
- 推进顺序：从 0 到 1（确认 idea 可行，保留靠谱的）→ 从 1 到 10（把可行的 idea 扩充为完整论文，对应"合"）。
- 有些研究的"1"天然存在，直接进入"合"。

### G2. idea 夭折的四个原因
1. 客观条件不允许。
2. 研究无法重复。
3. 信息缺失。
4. 原理错误。

### G3. 0→1 的最小验证
- 只关注验证 idea 是否可行的部分，不读性能测试、器件组装细节（这些属于 1→10）。
- 示例（假设）：某材料的包覆层形貌研究，0→1 的问题是"能否做出两种不同形貌的包覆层，并比较它们对性能的影响"。阅读重点是制备方法与如何判断制备成功。
- 若做出意外且有研究意义的新材料，可以转向（意外驱动）。
- 文献读不完不必焦虑：先聚焦解决当前问题的最小信息范围，不够再扩大。
- 对已分组的其他路线，不必放弃，调整阅读顺序：先读最快能达成里程碑的文献，失败再读其他路线。
- 好奇心驱动的研究：确认无人做过即可开始。

### G4. 0→1 不只是"能不能做"，还要看综合性能
- 示例（假设）：某正极材料提高某元素含量能提升能量密度、降低成本，但若牺牲安全性和循环寿命，工业界不会采用。0→1 要同时测试综合性能。
- 若新方案不比现有材料有优势，就没有使用理由。0→1 要评估关键性能。

### G5. 删除精简原则（验证链最小化）
- 不按时间或逻辑顺序机械地思考"先做什么后做什么"，而是尝试删除步骤，或把繁琐的制备替换为现成材料，只保留验证 idea 必需的关键步骤。
- 验证链必须保留"组装与测试"，否则无法判断 idea 是否可行。
- 示例（假设）：要验证某光响应电极的想法，有两种路线：
  - 路线一：先制备光响应电极，再组装测试（若 idea 不成立，难以判断是材料、组装还是测试的问题）。
  - 路线二：用已确认光响应特性的电极（甚至商业材料）组装测试 idea。
  - 建议选路线二，用否定法逐项排除。
- 教训：不敢问、不敢质疑已有的测试设置，是常见的耗时来源。遇到结果不理想时，先核对沿用的参数与设置，再考虑优化材料。

### G6. 其他领域的类比
- 医学：体外（in vitro）不成功就不进入体内与临床研究。文献阅读只关注体外方案，并汇总同类信息，防止以偏概全（有的体外方案无法直接用于体内）。
- 社会科学数据：从网络平台提取数据前，先想清楚"假设数据已提取，如何分析、如何与研究问题结合"，否则数据可能缺少关键字段。

## H. 《实验验证-1》文件：摘录

目的：不逐篇通读，把同类信息摘录到一个汇总文件，便于横向对比。

步骤：
1. 按分组选出需要摘录的文献（集中在同一分组）。
2. 从实验部分复制与材料制备相关的文字（如合成、表征等小标题下的内容）。
3. 表征图像（如形貌图）：不读正文，直接看图和图注，截图并带上图注。
4. 性能测试、电极制备、器件测试：若 0→1 阶段不必要，不复制。
5. 复制时不调整格式，全部完成后再统一字体。
6. 每条信息标注来源（作者、标题、期刊），标题化后下方依次粘贴摘录。方法同《引言-1》。
7. 理论研究（公式、代码、建模）的版本命名为《验证-1》。
8. 是否摘录性能测试，取决于 idea 是否需要它。原则：验证 idea 靠不靠谱必需的内容才摘录。

## I. 分组中的"下全文"流程

### I1. 选目标分组
- 从"已分类"组集中挑与目标相关的分组。
- 相关性弱的分组可暂不纳入。

### I2. 扩充分组
1. 检索词从标题扩展到摘要（判据见 C1）。
2. 扩展后的分组以检索词命名。
3. 人工筛选的分组用中文名。
4. 每个分组写一条"形成历史"记录。

### I3. 带读（快速阅读法）
- 逐一浏览分组标题，把可能相关的文献移入"XX 下全文"分组，统一下载全文。
- 方法要求：一个时间段只做一件事（只看标题，就只看标题；下全文统一另行完成）。

### I4. 摘要判断示例（假设）
- 摘要明确描述某类目标形貌：保留。
- 摘要只描述被覆盖、未描述目标结构：略过。
- 摘要描述的整体结构与目标无关：略过。
- 摘要中对象的主次关系与目标相反：略过。
- 表述模糊、无法确定：保留进下全文，留待判断。

### I5. 名称模糊的分组
- 按期刊排序取前 3 篇标题，看关键词所指。
- 标题能判断就判断；不能就读摘要；仍不能再下全文。
- 示例（假设）：某分组名可能指两种不同的物质，若是原子尺度结构，与宏观形貌无关，可略过。
- 若分组只有 1 篇文献，但摘要明确相关，保留，并将分组改名为"XX-下全文"。

### I6. 门槛调整
- 收集几十到上百篇时，只保留摘要中明确提及相关对象的文献。
- 不够再降低门槛。

### I7. 收尾
- 随时检查目标：选出的文献应至少涉及一种感兴趣的形貌，且不同文献的形貌差异足够大，便于设计对比实验。
- 文献已足够时，跳过剩余分组，直接进入实验方案制定。
- 扫尾："未分类"中的文献通过人工浏览分组清零。

### I8. 常见误区
- "为操作而操作"（只机械读标题、没有关联目标）。
- 为分组而分组。

## J. "信息越多越好"陷阱与"何时停止"

- 当你已经有足够的文献支撑当前问题，就停止，别因为"还没读完"而拖延。
- 备选 idea 不必越多越好，但至少备好 Plan B / C。
- "文献读不完"不是焦虑的理由：先聚焦最小信息范围，不够再扩大。

---

## K. 摘要中的"有价值"标准

- 有价值不等于"完全匹配"。如果一篇文献只能为你的工作提供 20% 的参考，也值得收录。
- 论文像拼图：若干碎片组合成完整拼图。
- 一篇文献完全覆盖你的问题，说明你的工作可能没有发表价值。
