# 选导师：用统计方法筛选 PI（advisor selection）

来源说明：本文件为通用方法归纳，不含任何原书或课程的具体案例、人名或机构信息。阈值（5年、70%、10% 等）为经验起点，应按自身情况调整。所有示例数字均为假设。

适用触发：选导师 / 导师筛选 / PI选择 / 报考导师 / 找博后合作PI / 评估某课题组的产出与延期风险。

核心思想：用"已经发生的数据"（近5年论文、已毕业学生的论文与学位论文）估计"进去以后大概率会发生什么"。所有比较都用比率，不用原始篇数。

---

## 0. 总原则（先读）

1. 大致正确优于精确错误。阈值只是起点，按自己的时间与风险承受力调整。
2. 先收集，后筛选，再联系。收集阶段不等于联系阶段，不要一开始就群发。
3. 只比较比率，不比较原始论文数。例如：100 人组发 10 篇与 10 人组发 5 篇，后者人均产出远高于前者。
4. 每一步都问自己：这一步是否回答了"毕业能否顺利、能否发高质量论文、延期风险多大"三问之一。

---

## 1. 第一步：收集候选名单（约数十到 100+ 个）

四个渠道：
1. 学院官网的师资页面（按目标学校、专业浏览）。
2. 新闻报道、公开资讯、同学或朋友推荐。
3. 文献数据库限定领域或期刊检索（如 WoS 限定某领域或若干目标期刊），找常在目标期刊发文的作者。
4. 把所有名字记入表格，暂不联系。

陷阱：收集完就群发，对自己和对对方都不负责。

---

## 2. 第二步：建立近5年论文履历表

每篇论文只记录决策需要的字段，其余（卷、期、页码、其他协作者）一律忽略：

| 字段 | 说明 |
|---|---|
| 发表年份 | 按年倒序 |
| 第一作者 | 通常是学生 |
| 通讯作者 | 标注通讯人数与单位 |
| 期刊 | 名称 |
| IF | 影响因子 |
| 分区 | JCR Q1-Q4 和/或中科院大类分区 |
| 关键词或标题 | 不熟悉领域时记全标题 |
| 类型 | 研究论文 / 综述（标题含 "advances"、"review" 等词常为综述） |

### 2.1 判定第一作者是不是学生
- 若第一作者在其他论文中以通讯作者身份出现，他/她大概率已是教职，不是学生。
- 综述会虚增产出，多数项目要求研究论文，统计时单列。

### 2.2 期刊分区查询
- JCR（Web of Science）：在期刊名检索处输入刊名，进入期刊页查看 IF 与 Category/Quartile。
- 中科院分区：可用国内分区查询网站（支持 ISSN 批量查询，比按名称查更快）。
- 注意：分区与 IF 跨学科不可直接比较。分区缓解了这一问题，但仍不完美，只作参考。

### 2.3 多个通讯作者的判读
| 情形 | 处理 |
|---|---|
| 目标 PI 为唯一通讯 | 直接记录 |
| PI + 同单位另一通讯 | 大导/小导式团队，核对脚注确认是否同单位 |
| PI + 外单位通讯 | 跨单位合作，不一定有日常指导；PI 仍是主要参照，但注明合作网络 |
| PI 只作为普通作者出现 | 说明其嵌入更大团队，考虑把那个团队的 PI 也列入候选 |
| 共同第一作者 | 记录共同第一作者占比；占比很高时，部分评价体系会按比例折算署名权重 |

---

## 3. 第三步：统计分析（核心三问）

目标：估计三件事
1. 能以第一作者发表的概率（毕业关键）。
2. 能发表高质量期刊的概率（求职关键）。
3. 延期的概率（时间成本关键）。

### 3.1 逐年对比：独立第一作者数 vs 论文数
- 对近5年每年统计：不同第一作者的学生数，以及论文总数。
- 若论文数持续多于独立第一作者数，说明多名学生各自能发多篇，产出可复制，是好信号。若只靠一两名"明星学生"，属于偶然，风险更高。

### 3.2 按学生汇总时间线
- 列出每名学生的：总论文数，各年分布。
- 无法直接确认学历阶段时，可用以下经验规则推断：
  - 3 篇以上、跨度 2-3 年以上：大概率是博士。
  - 1-2 年内集中 2-3 篇后再无新作：可能是硕士毕业，也可能是博士前期集中产出后沉寂。难分时去学位论文数据库（如 CNKI）查该学生的学位论文确认。
  - 1 篇且距今超过 2-3 年：大概率是硕士毕业。
  - 仅 1 篇且很新：无法判断，对总体结论影响不大，不必深挖。

### 3.3 估计招生规模（分母）
1. 查学院或学校的招生名额（正高通常多于副高；博士名额往往比硕士紧，除非刚获得重大项目或人才计划）。
2. 学制：硕士约 2.5-3 年，博士约 4 年（延期后 5 年以上）。
3. 估算组规模：年博士名额 × 博士学制 + 年硕士名额 × 硕士学制。
4. 比较估算值与履历表中实际出现的学生数：
   - 实际远多于估算：可能有外部或联合培养学生。
   - 实际少于估算：通常只是没有找全，估算偏保守，可接受。

示例（假设）：某组每年招博士 1 人、硕士 2 人，则估算规模约为 1 × 4 + 2 × 2.5 = 9 人。

### 3.4 核心指标：发表率
发表率 = 近期内以第一作者发表论文的独立学生数 ÷ 估计组规模（同一时间窗口）。

- 比较时用比率，不用原始数。
- 快速淘汰规则：发表率低于约 10% 时，可直接降低优先级，不必继续细算。

示例（假设）：估计组规模 9 人，近 5 年有 4 名学生以第一作者发表过论文，则发表率约 44%。

### 3.5 延期判断（两个互补代理指标）
1. 在学位论文数据库中查该组近几届已毕业学生的学位论文。论文附录通常列出在读期间的发表记录，可据此反推该组的实际毕业门槛（数量与质量），并比较入学年份与答辩年份，得到真实学制。
2. 使用第 3.2 节的时间线：若某学生从首篇到末篇论文的跨度超过约 4 年，是延期的软信号。注意误报来源：直博生、硕转博（本身合法的 5-6 年）、毕业后才发表的论文。应看整组中出现此模式的比例，不要因单个案例下结论。

快速版延期检验：从该组最近 5 篇学位论文中，若明显延期（如入学到答辩超过 2 年的额外时间）的比例低于约 70%，可通过此过滤。（这是经验阈值，可按自身风险偏好调整。）

### 3.6 期刊质量的解读
- 组的期刊分区分布是对"普通新学生"的天花板估计。若约七成论文落在 Q1，新人大概率也会主要落在 Q1，因为选刊、润色、人脉的平台效应远大于个人差异。
- 例外是"发动机"（engine）型 PI 或学生：他们会把天花板抬高。判断方法：组的产出水平是否在其到来后明显上升。

---

## 4. 快速版流程（时间紧时）

1. 确认近 5 年有多名不同第一作者，部分人一年 2-3 篇 → 无"长期零产出"风险 → 进入候选。
2. 抽查最近 5 篇学位论文，做粗略延期检验（第 3.5 节）→ 通过则进入下一步。
3. 只对通过两道粗筛的少数 PI 做完整统计（第 3 节）再排序。
4. 发表率低于约 10% 的直接降级。

---

## 5. 第五步：按"毕业后目标"决定排序权重（以终为始）

| 毕业后目标 | 最重要的指标 | 排序方式 |
|---|---|---|
| 学术岗（教职） | 在细分领域的竞争排名（论文在同方向竞争池中的相对位置） | 优先选产出天花板高的组；考虑细分方向是"热门且拥挤"还是"较小众" |
| 产业界 | 低延期率、学位与学校背书 | 按延期率从低到高排序；有企业合作项目可加分，但不能影响毕业 |
| 特定职业路径（如行政、思政等） | 直接确认该路径的去向 | 直接询问该路径的现任从业者，而不是只看论文统计 |

补充要点：
- 小众细分方向有时更好：在较薄的竞争池里排前 50% 可能比在拥挤的热门赛道排前 10% 更容易。
- 产业界的研究生，所学专业与最终工作往往不完全相关，因此产业界路线更看重学历背书与可控的毕业时间。

---

## 6. 决策收尾：停止排序规则

1. 层层筛选后缩小到约 50 个，按第 5 节权重排序，依次申请，被拒、无回复或无名额就立即换下一个。
2. 当缩小到前 10-20 名、仍无法可靠区分时，停止排序，把这一档视为等价，任选一个，不要陷入犹豫。
3. 长时间权衡而不行动，代价往往大于随机选定一个可接受的选项。

---

## 7. 对论点的诚实边界

- 统计方法预测的是"结果概率"（能否毕业、能否发表），不能预测主观体验（压力、人际关系、心理成本）。
- 即使统计结果很好，导师的个人风格仍可能带来很差的体验。
- 用证据选导师的价值在于：至少避免最差的情况——一条看不到终点的隧道。知道有终点，过程会更可承受。

---

## 8. 常见陷阱速查

| 陷阱 | 识别方法 |
|---|---|
| 第一作者几乎全是 PI 的同事，或第一作者反复作为 PI 其他论文的通讯出现 | 学生署名疑似被挪用的迹象：核对该学生是否在多数论文中仍保留第一作者位置 |
| 零论文但被当作"新组" | 核对 PI 简历确认是否真的新任；若是新任，用其在前单位学生时期的产出作为天花板代理，并看"发动机"迹象（其个人高水平工作是否明显抬高过前组的天花板） |
| 把综述当研究性产出 | 标题含 review、advances、perspective 等，单列统计 |
| 把共同一作当完整一作 | 共同一作按权重折算 |
| 只看一个亮眼指标 | 必须同时看发表率、延期、期刊分布三者 |
| 把直博或硕转博算作延期 | 先确认学制类型再判断 |

## 9. 最小可执行清单

- [ ] 收集候选名单（4 渠道），暂不联系
- [ ] 为每个候选建近 5 年履历表（第 2 节字段）
- [ ] 标注每篇的一作、通讯、期刊、分区；剔除综述（单列）
- [ ] 逐年比较独立一作数与论文数
- [ ] 估算组规模，算发表率；低于约 10% 降级
- [ ] 查近 5 篇学位论文做延期粗检
- [ ] 按毕业后目标选择排序权重
- [ ] 排序→依次申请→停止排序规则
