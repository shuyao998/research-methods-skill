# 模块化工具与心法（研究流程模块 + 心法模块）

通用的研究流程模块与心态工具，按"研究模块 1.x + 心法模块 2.x"组织。各模块要点为作者概括与改写，不是逐字引用。

适用触发：不知道做什么 / 没有焦点 / 怎么发论文 / 发表路线 / 读文献的误区 / 应试思维 / 公式代码看不懂 / 合作关系 / 合作难推进 / 与导师的关系 / 被否定或不公平对待 / 自尊心受伤 / 烦心事无法行动 / 拒稿后低落 / 以终为始怎么用 / 多个选项不知道选 / 与导师或权威交流紧张 / 人生下限 / 靠谱 / 科研心态 / 延期 / 焦虑。

核心思想：只做"有输出"的动作。每次使用这套方法，先确定当前需要的输出，再只执行对应步骤。心态问题用"动作"而不是"想通"来解决。

---

## 0. 总纲（先看这里）

1. 无输出，不阅读。先写下需要的输出，再读对应章节，边读边按说明操作。
2. 以终为始有适用范围：只适用于"不得不做"的事（如毕业）。在此基础上再扩展其他可能性。
3. 步骤不能少，定量可以缩。时间紧时，可以把文献数量、实验次数等定量指标按比例压缩，但流程步骤不能缺。
4. 选择权先于选项。只有你真正有选择权的选项才值得比较。
5. 用行动代替想通。情绪与矛盾不靠"想开"处理，靠占满注意力的低门槛动作处理。

---

## 1. 研究模块（1.1–1.6）

### 1.1 没有焦点，不知道眼下做什么（毕业导向的拆解）

核心：把"顺利毕业"拆成可执行的动作，聚焦在发表研究性论文上。

步骤：
1. 参考同组近期毕业学生的学位论文，看结构。学位论文通常由引言、研究方法、结果与讨论三部分组成，其中结果与讨论最关键。
2. 先做结果与讨论，而不是按章节顺序从引言写起。结果与讨论确定后，引言和方法很快就能写完。
3. 每篇小论文对应一个结果与讨论章节。小论文之间要递进：前一篇解决"为什么失效"，后一篇提出解决方案，再后面的篇目改进方案的缺点。
4. 发表时间不可控（审稿、返修、可能被拒），所以应优先安排最不可控的环节：小论文发表。
5. 若时间极紧，可在"验证"完成后同时进行数据收集与引言写作（以 idea 已验证为前提，避免大面积返工）。
6. 不需要发表小论文的人（如只写毕业论文），用同样的三阶段：选题 → 验证 → 整合（图表公式与文字）。

### 1.2 发表研究性论文（三阶段流程）

阶段 1：开题（找 idea）
1. 判断层级：
   - 第一层：只知道大领域，不知道具体做什么。从组内近期论文标题、导师处取关键词。
   - 第二层：关键词太笼统，检索结果数万篇。需要叠加或细化关键词，把结果控制在约 1 万篇以下（最好几千篇）。
   - 第三层：关键词已足够细，可以开始找 idea。
2. 细化方法：
   - 叠加限定词。不要叠加几乎所有论文都会涉及的通用词，加了等于白加。
   - 用检索引擎测试结果数量，并对照导师的研究方向，判断是否合适。
3. 反问法检验：假设选题覆盖了这些关键词，导师会不会否决？若会，继续细化。
4. 两个维度决定如何检索：
   - 维度 1（追求高质量发表）：限定到领域的目标期刊检索，结果几百到几千篇。
   - 维度 2（追求尽快产出）：按日期倒序，翻 1-2 页只看标题，找新关键词。看不懂的标题直接略过。
5. 跨领域关键词：不要只用直译。同一概念有多种写法，都要纳入检索词。
6. 备选 idea：先找到 5 个左右 idea，设计备选方案。一开始就两三个并行，等待实验结果时测试其他 idea。
7. 新人不需要等导师给题：完成搜、聚、分后，通常会浮现大量朦胧 idea，再由验证筛出可行的。

阶段 2：验证 idea
- 用最少工作量、最短时间判断 idea 是否可行，淘汰不可行的。
- 不是所有 idea 都需要验证（已确定能完整扩展成论文的，可直接进入阶段 3）。
- 多个 idea 时，按"想发更好的论文"或"更快发表"两个维度选择；仍难选则选一个，一测就知道行不行。
- 验证细节见 secondary-grouping-and-verification.md 第 G 节。

阶段 3：扩充完整研究结果（整合）
1. 整合图、表、公式：先确定发表所需的系统结果，避免写作时才发现缺数据或数据有误。
2. 整合文字：文字素材库流程（6 个子步骤，见 writing-sentence-bank.md）：
   - 选 5-25 篇素材文献（时间紧 5-10 篇；宽裕也不超过 25 篇）。
   - 复制指定区域文字，集中存档。
   - 标签化。
   - 按标签生成分类素材文件。
   - 按逻辑重排标签。
   - 做选择题，逐句写出论文。
3. 时间紧时，图表公式整理与文字整理可以并行。

### 1.3 消除阅读文献的误区（输出导向，而非泛读）

核心：不要漫无目的地读文献；读文献只为了得到某个输出。

1. 常见误区：文献读不够、一篇篇做笔记、读到几十篇后忘掉前面的。面对信息爆炸与噪声（不可复现的实验、错误结论），逐篇精读的效率很差。
2. 读文献的三类目的：
   - 目的 A：不知道做什么，要找选题与 idea。
   - 目的 B：知道做什么，不知道怎么做（设计研究方案、解决困难）。
   - 目的 C：已有结果，要发表论文。
   - 青年教师另有：为团队找 idea；解决学生或自己的研究困难；写项目申请书。
3. 对应的操作：找 idea 用搜、聚、分；设计方案与解决困难用验证与图表公式整理；发表用文字整理。不需要单独的"看文献阶段"。
4. 输出上限：给自己设定上限（例如找到 5 个 idea 就停），否则会陷入无休止的信息搜集。
5. 动作带动理解：暂时看不懂的句子不必纠结，继续操作，写完论文后自然会懂。
6. 自查：如果在操作中又陷入"读了但没有输出"，说明方法使用有误。停下来，问自己当前要的输出是什么，再去索引对应章节。
7. 文献的噪声与错误：即使是发表的论文也会出错。引用不等于正确，书籍也可能转引错误。要用复现或检索去核实。

### 1.4 消除应试思维（输出式提问）

核心：研究阶段不要问"每天怎么安排"或"学到什么程度"，应问"我现在要什么输出"。

1. 把应试式问题改成输出式问题。六个自问：
   (1) 我知道要做什么研究才能发论文吗？
   (2) 我的 idea 靠谱吗？能否尽快识别其不靠谱？
   (3) 我是否保持开放，不把意外当作失败抹杀？科学史上许多重要发现都源于意外。
   (4) 研究遇到困难，我知道怎么设计研究方案解决吗？
   (5) idea 验证可行后，我知道需要哪些结果才能发表吗？
   (6) 有了结果后，我知道怎么写出让人跟得上逻辑的文章吗？
2. 每个问题对应一组输出（找思路、验证方案、意外发现、解决困难的方案、完整研究方案、系统结果、文字素材库、论文文字）。
3. 公式与代码看不懂，不要先硬啃：
   - 先复现：找有源码、有建模参数的文献，把代码或仿真模型跑通。
   - 能跑通后再拆开理解每个模块。
   - 复现失败说明文献的源码不完整，换一篇即可（这本身也是有价值的信息）。
   - 仿真可借助成熟软件的案例库；算法可借助现成工具包。
4. 公式推导也可借助数学软件或大语言模型辅助核查，但工具输出同样可能出错，需要人工复核。
5. 不要把"看懂公式"当成发论文的前提。
6. 教材顺序不是研究顺序：很多工程实践先于理论，应从实践出发。
7. 口述的好处：先说出来再写，可以建立听觉通道，帮助理解与行动。

### 1.5 合作关系（合作与团队）

核心：换位思考，找双赢。

1. 团队任务分配：
   - 先了解每个成员的诉求（多为毕业与发论文）。
   - 把任务拆解成与各人目标直接相关的部分：低年级给数据与实验方案，高年级给可写作的部分，已接近毕业者给辅助性帮助。
   - 有人不愿参与也没关系，争取头部约 10% 的核心成员即可推进（二八或幂律分布）。
   - 社会认同效应：多数人参与后，犹豫者也会跟进。
2. 与导师的关系：导师的诉求通常是出成果、能继续申请项目。发表高质量论文本身就是双赢。专注出成果，不必刻意经营社交。
3. 事务性工作：
   - 观察自己的节奏：高强度研究后需要切换，等待实验结果时也有空档。
   - 把最优质时段给重要而非紧急的工作（如实验与写作），把事务安排在空档处。
   - 事务有时也有收获（如参与项目书撰写能学到不易接触的资料）。
   - 若事务严重挤占主线任务，应用工时等证据与导师沟通调整分工。
4. 与外部合作者：
   - 先明确收益分配（共同通讯、共同第一作者，还是只是听从安排）。
   - 合作者没有实质收益时，推进会很慢。若自己无法推动，可通过合作者的上级沟通。
   - 同时准备备选方案。除极少数不可替代的设备，大多数资源可找到替代方案，有时自费比延期的代价小。
   - 主动询问合作方有没有需要帮忙的，必要时协助解决对方的障碍（注意保护对方的商业机密）。
5. 应聘与工作：要了解对方的诉求和需要的输出，而不是只强调自己的背景。雇主付出的是薪水，换来的是输出。

### 1.6 框架与使用方式

1. 输出清单（按输出查章节）：
   - 有潜力的发文 idea → 搜、聚、分。
   - 低成本验证 idea 的方案 → 验。
   - 验证中产生的意外发现 → 选题章节。
   - 完善的研究方案 → 整合图表公式。
   - 研究论文 → 整合文字。
   - 综述 → 综述写作。
   - 返修与答复 → 修改稿整理。
   - 毕业论文、答辩、毕业后选择。
   - 指导团队、职业路线、申请书。
   - 解决群体性的真实痛点、提升对真实世界的认知。
   - 具体章节名以原书为准；本 skill 只保留输出与对应主题的映射。
2. 两种极端要避免：
   - 极负：觉得案例与自己领域差太远，跳过细节或省略步骤。
   - 极正：把案例当成不可更改的规定，一字一句照搬。
   - 理性的做法：保持定性步骤完整，定量参数按自己的领域调整。
3. 鲸鱼式检索的思路：less is more。先大口吞入（宽检索），再快速筛出（分组）。宁可多吞，但要保证不漏掉关键文献。
4. 先发一篇论文。第一篇不必追求最高影响因子；走完一次完整流程，才能知道全貌，下次再提高目标。
5. 时间紧时，不要砍步骤，而是砍数量。被砍掉的步骤往往会让工作量成倍增长，或导致找不到 idea 或无法写作。

## 2. 心法模块（2.1–2.6）

心法模块处理"失焦"：被否定、自尊受伤、烦心事、选择困难、人生困惑。核心都是把注意力从无法控制的事上移开，放到低门槛、可执行的动作上。

### 2.1 面对不公平对待或被否定

1. 不必急于判断对方是否在刻意打压，判断意义不大。
2. 认知工具：很多条件（如出身与基因）本就不由自己决定，别人也不可能完全掌控你的人生。
3. 幸存者偏差与分母统计（核心方法）：
   - 只看成功者（分子）容易得出"努力即成功"的结论，但失败者（分母）没有发声。
   - 示例（假设）：若某件事的成功率是 1%，一千人中总有一人"成功"。他的成功归因于自身努力，却忽略了其余九百多人同样努力却失败。
   - 检验方法：统计分母。例如判断某人业绩是否可持续，需统计长期表现的比例与随机水平的差异。
4. 不是否定努力，而是正确认知自己与世界的关系。不建议以损害身体的方式工作，健康与心理状态会影响输出质量。
5. 不要让别人给自己下定义。每个人的特质大多是先天的，别用对方的模板要求自己。
6. 心理的抓手：不要卡死在"必须走这条路"。越觉得非此不可，越容易被左右。知道自己有其他选项，对方就很难拿捏。
7. 实际抓手：先确保阶段性终点（如顺利毕业），再谈其他。

### 2.2 在意他人评价（在远方设置焦点）

1. 不要问"如何降低自尊心"或"如何不在意评价"。问这个问题本身说明评价正在深刻影响你。
2. 把焦点放在远方的目标（如毕业、毕业后去向），眼前的评价只作为环境噪声。
3. 把注意力放在三个具体问题上（选题、实验、发论文）：
   - 我知道要做什么研究吗？没有 → 按 1.2 阶段 1。
   - 实验设计有没有根本错误？不确定 → 按 1.2 阶段 2。
   - 有没有系统结果可以写论文？没有 → 按 1.2 阶段 3。
   - 实验包括编程、计算、仿真、公式推导、临床、实证调查等，只要是真实世界的探索都算。
4. 远方的参照：高处俯瞰。近处的喧闹，在高处只是背景。
5. 低耗能步骤：能量低时，高门槛任务会让人逃避，逃避又进一步耗能，形成恶性循环。
   - 把大任务拆成最小台阶，每个台阶的耗能尽量低。
   - 写作时，不写"完成整篇论文"，而写"今天完成引言前几句"。
   - 能量极低时，先做最小的事（如整理几篇素材文献）。
6. 不要试图"忘记"负面评价。越想忘，越会反复想起。用行动占满注意力。

### 2.3 烦心事与人际矛盾（转移注意力）

核心：不直接处理情绪和矛盾（它们往往无法直接解决），而是转向一个能解决的新问题或动作。

1. 不直接处理负面情绪。情绪是大脑对事件的解读，越想控制越强化。
2. 找到当下门槛最低、能量消耗最低，甚至能补充能量的动作：
   - 运动、写作、阅读推理类读物、去自然环境散步、冥想式的呼吸关注等。
   - 不要用"调整心态"这类说法，它会强化对负面事件的注意。
3. 多事件型与单线程：
   - 同时推进多个事件（如两三篇论文同时投），一篇被拒，其他仍有希望。
   - 但每个时间段只做一件事（单线程），大脑不擅长多线程。
   - 构思其他重要成果的过程，也能把注意力从烦闷中解脱出来。
4. 拒稿的处理：
   - 申诉是一个动作，做完即放下，不对结果有期待。
   - 创新性强的研究往往更容易被拒。被拒不等于质量差。
   - 论文被拒后，可以改投，也可以用其他成果推进。
5. 人际矛盾的处理：
   - 不必卷入矛盾。把注意力放在与毕业相关的主线动作上，对方的矛盾大多不影响主线。
   - 在主线动作中，对方往往无法提供实质帮助，因此不必在对方身上消耗情绪。
   - 公共事务：只占用约 20%-50% 的精力（方法效率高时，主线只需 50%-80%）。把剩余精力用在事务上，获得回报是额外收获。
   - 若某些事务严重挤占主线，用证据（如工时记录）与导师沟通调整。
   - 设备被占用等资源矛盾：向导师反映（多人反映比单人更有效），或寻找校内其他资源、外部服务平台。
6. 常见的有效做法（概括）：
   - 实验失败后出去走走，心情明朗后再回来换新的方案，往往更快得到初步结果。
   - 烦闷时写作，写作中暂时忘记烦心事，写完后烦闷已减弱。
7. 睡眠的重要性：晚上纠缠烦心事，常得到差的或错误的结论，且第二天思路不锋利。睡眠有助于认知，不要强行在夜里解题。

### 2.4 以终为始的使用误区（止损与终点）

1. 以终为始的适用范围：只适用于"不得不做"的事情，如毕业。
2. 终点是可选的，不是必须的。很多成功者并不依赖某个学位路径。
3. 止损的判断：
   - 若身心已持续严重受损，或周围多数人无法完成，可考虑止损（换方向、换导师或学校、提前就业）。
   - 但创业不是逃避的选项，难度更大。
4. 沉没成本：决策应以未来价值折现到当前来衡量，忽略已投入的成本。
5. 终点的多样性与不可预测性：很多人的人生终点在当时无法看清。当下的"失利"未必是最终结果。
6. 操作：先搞定阶段性终点（如先确保毕业论文的结果章节和发表）。阶段性目标完成后，才有机会选择更有趣的环境。

### 2.5 多个选项不知道如何选（选择权与选择）

核心：先区分"选择权"和"选项"。只有有选择权的选项才值得比较。

1. 先确认选择权（加滤网）：
   - 对每个候选，问：对方是否真的会给我这个机会？我是否真的能拿到？
   - 很多选项只是"看起来有"（如口头认可、他人的评价、自己的印象），实际上可能根本没有。
   - 尽快与对方接触（如直接询问导师）。在没接触前自我想象只会内耗。
   - 申请或面试中，如果没有 offer，先不要纠结，多投递，把时间用在能获得有效选项的动作上。
2. 选择权上做加法：多尝试、多接触、多投递，获得更多"有选择权"的选项。
3. 选择上做减法：当有多个选项时，用滤网排除，只对有效的少数选项做深度分析。
4. 两个维度决定如何选：
   - 维度 1：以终为始。毕业后想做什么（进高校、公务员、企业）？对应的选择标准不同（如进高校看发表水平，企业看薪酬与延期率）。
   - 维度 2：用身体接触。面谈、实地参观、与团队交流，感受压迫感、氛围、是否愉快。身体的感受是可靠的参考信号。
   - 证据导向（统计）与身体感受要结合，不要只凭一次好印象。
5. 选不出来时：如果只剩一个有效选项且没有明显大坑，先选上，成长优先于完美。之后换方向相对容易。
6. 大脑算力分配：采用本方法只需 50%-80% 的精力，剩余可用于其他选择或事务。
7. 真实的选择权数量：多数人只有一个有效选项，极少数有两个。
8. 意义感与使命感（反证法）：
   - 意义感难以正向定义，但能确定它不是什么。若某件事"有没有意义"的问题本身让你无感，说明它对你没有意义。
   - 不确定想做什么，就先排除肯定不想做的。
   - 排除后剩下的选项，即使不完美，也可以先做。
9. 与权威（导师）交流的畏惧：
   - 畏惧是正常心理，不必克服，只需缩短等待期（不要在交流前长期预演，尽快交流）。
   - 交流后会出现三种结果：畏惧成真（可以排除选项）、对方难相处（需要重新考虑是否值得投入数年）、畏惧是多余的（可能得到建议）。三种都有价值。
10. 反面情形（假设性概括）：
   - 有人在某阶段很痛苦，只因"周围人都在某个方向"就跟随选择。应先用证据统计该组的延期率与发文率，再用身体感受判断。
   - 长期高强度、睡眠不足的工作方式，不应被当作成功的标准。

### 2.6 提高人生下限（靠谱与重新界定问题）

1. 重新界定问题：把看似具体的问题还原为更本质的问题。问题提得对，很多具体问题就不再需要单独解决。
2. 两个关键：
   - 持续向身边人、前辈请教、求助（这是一种行动特点，应保持）。
   - 靠谱。事事有回应，说到做到。
3. 靠谱的定义：
   - 你说出去的事情，一定有回应，无论成功或失败。
   - 失败时说明过程、结果与解决方案，而不是沉默或找借口。
   - 做不到的事就不要答应，或者明确说"没把握，试一下"。
4. 人生下限高，不取决于文凭或分数，而取决于是否靠谱，以及是否在靠谱的平台或人身边。
5. 统计分母的视角：不要只看成功的案例，统计未成功者发生了什么。每个分支都有幸存者，也有大量沉默的失败者。
6. 长板与木桶：不必用短板去拼别人的长板。你的长板可能比别人的长板更适合你。
7. 平台与机缘：个人能力很重要，但机缘与平台的作用也很大。靠谱的人容易遇到靠谱的平台；不靠谱的人容易被不靠谱的平台吸引，短期成功后可能跌得更惨。
8. 识别靠谱的平台或人：
   - 统计其过去的承诺，看兑现率。可设定阈值，如六成及格，八成以上为较好（不要求百分之百，意外总会发生）。
   - 观察是否分享过收益、是否有兑现的先例。
   - 不听他说了什么，而看他做了什么。
9. 靠谱的职业路径：自雇型工作（如技术服务、整理与助理类工作）在靠谱的人身边，积累的认知与收入可能超过普通打工。
10. 输出倒逼训练：提高能力的关键是以输出（做题、写作、实践）倒逼训练，而不是被动地学习。
