# Experimental Troubleshooting as Debugging

Source: 方法篇A 的第3章（实验研究）。该方法借鉴了软件调试的思路，并可迁移到实验科学。所有示例均为通用假设示例。

## 1. 从选题到实验设计——延续根因链
实验设计承接选题阶段的根因追问（交叉参见 `01-topic-selection-and-literature.md` §4）：继续分解研究问题（“如何提高反应速率？”→“反应有哪些子步骤？”→ 吸附 / 反应 / 脱附），直到得到一个足够具体、可以围绕其设计实验的子步骤。这一“剥洋葱”过程会与文献检索交互：实验设计越清晰，越要回到知识库，甚至检索相邻领域（例如，两种电池体系的氧还原化学相通，可互相借鉴文献），以进一步细化。同时，可对相关论文的“方法”部分使用切块重组阅读法，了解他人在参数选择上的范围，再定稿自己的方案。

## 2. 结果无法复现的两类常见模式
当实验结果远偏离设计预期时，可区分以下情形，其中两类较常见、也较易处理：
- **poor reproducibility（重复性差）**：多次重复结果不一致。
- **complex / irregular reproducibility（复杂或不规则的重复性）**：有时能复现，有时不能。
- （另有一类“重复性很好但就是不起作用”，单独处理，见下文 §4，它往往是更重要的发现，而不是 bug。）

对于前两类，**不要从头到尾逐步检查每个环节**——这样慢，而且容易丢失整体目标。应使用下面的调试式技巧。

## 3. 四种调试技巧（附通用示例）

### 3.1 “以终为始”+ 简化/替换/排除/节点测试
把实验流程当作一段无法逐行阅读的代码来对待，去找“bug”。
- **排除法**：把某个功能模块“屏蔽”——强制其输出一个固定的已知值——然后检查整体输出是否符合预期。若符合，则被屏蔽的模块就是问题所在（搜索范围收缩到它）；若不符合，问题在别处（可能仍与该模块有关，也可能无关），换另一个模块重复上述操作。
- **节点测试法**：沿流程插入几个关键里程碑检查点，在每个节点验证系统是否符合预期。类似于计算机无法启动时，逐个拔插内存、硬盘、显卡来隔离故障，而不是凭猜测修改。
- **简化/替换**：用已知可靠的替代步骤或材料替换、剥离某些步骤，以有计划、分阶段的方式缩小故障范围（不要随机改动）。

### 3.2 极致分解——通用示例（假设）
当重复性不一致且没有明显规律时，自上而下分解为可独立测试的子模块，每个子模块都用已知可靠的参照验证后再进入下一步：
1. 把“在[电极基底]上电沉积材料，然后测试其新的电化学信号”拆分为：① 沉积步骤，② 测试步骤。
2. 单独测试 ①：沉积材料后，在一个经典、成熟、重复性高的电化学体系中测量。若结果稳定，则 ① 基本排除，问题在 ②。
3. 替代测试 ②：在*新的*测试体系中使用一个商用或已知可复现的参照材料。若参照能稳定复现，则 ① 是可疑对象；若参照也失败，这本身就是一个新的发现（新测试体系存在固有问题，而不是 ①）。
4. 定位到 ① 后继续细分：①.1 基底本身 vs ①.2 沉积工艺。替换基底（例如换用其他导电材料，并严格控制接触几何与面积）——若重复性恢复，则基底是问题来源。
5. 继续细分基底：该电极结构由“内芯 + 绝缘护套 + 引出线”组成，可进一步拆分为 ①.1.1 内芯材料本身、①.1.2 **内芯与护套之间的接缝**、①.1.3 内芯与引出线的连接（最容易排除，直接测接触电阻）。示例（假设）中，根因最终在 ①.1.2：反复打磨（用于彻底去除先前沉积物）使接缝逐渐变宽，杂质颗粒和意外沉积进入缝隙，污染了后续测量。打磨后用熔融石蜡密封接缝，重复性随之恢复；随后在电子显微镜下确认接缝缝隙确实存在，并暴露出额外的导电边缘面积。

**通用教训**：所有人都默认“不可再分”的细节（认为不值得质疑），恰恰是隐藏 bug 的地方。持续追问“这真的像大家以为的那样牢固吗？”，并用自己的测试验证，而不是因为实验室传统就照单全收。

### 3.3 同一模式的更多示例（追溯测量来源，假设）
- **温度测量位置**：惰性气氛热处理炉显示的温度来自炉腔外的热电偶，而不是样品所在位置，显示温度与样品实际温度之间存在差距。根因链：我们如何知道温度？→ 仪表显示 → 显示读数来自哪里？→ 热电偶 → 热电偶是否真的位于我们以为的关键位置？→ 实际检查其位置 → 发现偏差 → 改造为热电偶位于炉腔内、靠近样品。
- **试剂降解**：某个结果在交接给新成员后不再复现；通过排除法追溯到一瓶过期试剂，其有效浓度已明显低于标称值。解决办法：用新鲜试剂做稀释系列，重新找到真正起作用的低浓度区间。
- **水质**：某个稳定的电化学结果突然失败。根因追问（“我们如何确定水中没有干扰杂质？有人验证过电阻率吗？”）发现纯水装置没有电阻率读数，无法确认其达到标称纯度；换用经验证的高纯水后问题解决。
- **沿用的实验室习惯**：不要默认沿用的流程或设备没有问题。检查参比电极或 pH 计是否近期校准。在会释放腐蚀性气体的腐蚀试验中，电极夹具即使被防护塑料套保护，也可能在无明显迹象的情况下被悄悄腐蚀。
- **模板的不对称性**：某纳米结构生长结果不一致，通过对比原始模板与成功/失败产物的电镜图像，发现所用阳极氧化铝模板的正面光滑、背面粗糙；需要粗糙面与集流体接触才能获得良好结果，而原始流程未对此进行控制。

### 3.4 新想法的快速验证（“以终为始”用于新想法，而非仅用于调试）
评估一个全新的实验想法（而非排查已有实验）时，不要一步步执行完整的计划序列——这样可能在发现整个方向不可行之前投入大量资源。应当：
1. 定义“终点”——什么结果能证明该想法至少是可行的？
2. 从终点倒推，找出到达终点所必需的**最少关键里程碑步骤**，跳过或替代本轮不必要的环节。
3. 本轮优先采用极端条件测试，以及商用或现成材料（若商用材料可以替代需要自己合成的材料，就直接使用）——先回答**0→1 问题（是否根本可行）**，再回答**1→100 问题（如何优化）**。
4. 若快速验证失败，先用 §3.1–3.3 的技巧找出原因，再决定是放弃还是继续。

## 4. 可复现但出乎意料的结果——不要丢弃
如果一个结果稳定可复现，但与设计预测不符，这说明可能存在不同于假设的真实控制机制——应当追查，而非当作噪声或失败（与 `01-...md` §4 的“发现与成长”视角一致）。历史上，一些高度可复现却“看似错误”的结果，恰恰改写了整个模型。

## 5. 实验记录与样品管理——保证事后可追溯
核心原则：每一个操作都应能在事后被追溯。
- **双栏实验记录本**：左栏按时间顺序，详细记录每一步实验步骤与条件（包括看似常规的步骤）；右栏记录从该次实验中得出的观察、想法与备注。左栏有两个用途：事后重建精确条件，以供写作；以及日后诊断问题、启发新方向。**实验记录本不仅仅是结果日志**。
- **示例（假设）**：某结果不再复现。回看带日期的记录，发现早期成功的实验都在室温较高的季节进行，而失败的实验都在室温较低的季节进行。根因是温度，解决办法是空调与恒温水浴，把包括清洗液在内的所有工艺用水保持在恒定温度。
- **示例（假设）**：某结果只做成过一次，无法放大。逐项回看记录中用到的每个参数，发现原始实验与后续尝试之间对电极做过更换——这是被忽略的变量。
- **因素众多的实验**：可用视频与音频记录过程（如同行车记录仪），以便日后回放时发现当时未曾记录的条件。
- **样品保留与编号**：保留所产生的每一个样品——包括失败品、半成品、原料与中间产物——每个都有唯一编号，并与记录本中描述其全部步骤的条目交叉对应。这使得之后进行对比表征成为可能。示例（假设）：把保存下来的原始模板与成功及失败产物一起做电镜对比，正是这种对比揭示了 §3.3 中所述的正反面不对称。

## 检查清单（实验排错阶段）
- [ ] 是否先用排除法或节点测试缩小范围，而不是逐步从头检查？
- [ ] 是否对“看似牢固、无需质疑”的环节做过独立验证？
- [ ] 测量仪表的读数，是否确认过其位置与实际关心的对象一致？
- [ ] 试剂、纯水、参比电极、夹具等基础条件是否近期验证过？
- [ ] 可复现但意外的结果，是否已被当作潜在机制线索而非噪声？
- [ ] 每一步操作是否都有时间戳、条件记录，并保留了对应样品？
- [ ] 新想法是否先用最少步骤做了 0→1 的可行性验证？
