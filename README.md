# research-methods-skill

A Claude Code skill with generalized research workflow methods: literature search and grouping, research-gap and topic finding, experiment debugging and verification, paper and introduction writing, pre-submission self-checks, proposal writing, advisor selection by publication statistics, and research mindset tools.

The content is a generalized summary of methods from published and public research-methodology sources. Book- and course-specific examples, names and case studies have been removed; examples are labelled as hypothetical. This repository does not reproduce any source text.

If you are a rights holder and believe any content infringes your rights, please open an issue and the content will be removed.

## Install

Copy `research-and-paper-writing-method/` into `~/.claude/skills/`.
